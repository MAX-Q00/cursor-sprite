# Cursor Sprite

Show any game sprite, item icon or game cursor image next to your mouse pointer. Browse and search every sprite, item and cursor, or type an item ID. Size, offset, opacity.

Current version: 0.1.23

- Install from mod.io: https://mod.io/g/runescape/m/cursor-sprite

## Report a bug or request a feature

Open an issue: https://github.com/MAX-Q00/cursor-sprite/issues/new/choose

For a bug, please include the plugin version, what happened, what you expected, steps to reproduce, a screenshot if you can, and your game resolution and UI scale.

Contact: Dylan@quspace.agency
